Jarvis

Talk. Your agents work.

curl -fsSL https://sangdth.github.io/jarvis/install.sh | sh
$ jarvis
you:    Push my changes and open a PR.
jarvis: I pushed it, but there was nothing for a PR.

What it does

  • Sends coding to T3 Code, Claude Code or OpenCode, and the rest to Hermes.
  • Tells you each outcome in one short line.
  • Asks you before an agent does anything that needs approval.
  • Optional: acts only on your voice. jarvis enroll turns it on.

How it hears

Mic → Whisper → Intent → Brain → Voice

No wake word. It answers only when you talk to it.

Start

jarvis init
jarvis

Apple Silicon Macs. Setup and voice commands: README on GitHub.
