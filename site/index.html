Features

A thin layer that stays out of your way.

Jarvis routes and relays. The work, the tools and the memory stay in each agent's own harness.

[ 01 ]
◎

Your voice only

Every sentence is checked against your enrolled voiceprint locally using sherpa-onnx. Other voices are dropped and cannot interrupt or keep Jarvis waiting.

[ 02 ]
?

Answers when you mean it

No wake word. A fast decision model distinguishes conversation aimed at Jarvis from background talk around it in roughly 230 milliseconds.

[ 03 ]
→

Right agent, every time

Coding prompts route to T3 Code by default, or Claude Code / OpenCode when named. Ambient research, calendar, and general tasks route to Hermes Agent.

[ 04 ]
/

Projects by name

"Continue on the Hugger Hustle platform" locates the project repository under ~/Projects and opens a T3 Code thread synced with master.

[ 05 ]
!

Approvals stay yours

Agent questions and dangerous tool executions are read to you word for word. No autonomous model ever approves anything on your behalf.

[ 06 ]
♪

Quiet when you need it

"Shut up" switches output to soft beeps and queues background events. "You can talk" brings a consolidated spoken digest of what you missed.

System Architecture

Built on Pipecat. Local where it counts.

Speech recognition and the voice check run on your Mac's GPU and CPU. Only your own validated sentences leave the machine.

Get started
# 1. install dependencies
$ uv sync

# 2. configure api keys (OpenRouter, ElevenLabs, Hermes)
$ cp .env.example .env

# 3. enroll your local voiceprint (three sentences)
$ uv run jarvis-enroll

# 4. launch jarvis voice harness
$ uv run jarvis

Let the agents work. Go live your day.

Jarvis keeps you in the loop in two sentences, and waits for your "yes" wherever you are.
