Features

A thin layer that stays out of your way.

Jarvis routes and relays. The work, the tools and the memory stay in each agent's own harness.

◉

Your voice only

Every sentence is checked against your enrolled voiceprint, locally. Other voices are dropped and can't interrupt Jarvis or keep it waiting.

?

Answers when you mean it

No wake word. A fast decision model tells talk aimed at Jarvis from talk around it, in about 230 ms.

→

Right agent, every time

Coding goes to T3 Code by default, or to Claude Code or OpenCode when you name them. Everything else goes to Hermes Agent.

/

Projects by name

"Continue on the Hugger Hustle platform" finds the repo under ~/Projects and opens a T3 Code thread that syncs with master.

!

Approvals stay yours

Agent questions and approvals are read to you word for word. No model ever approves anything on your behalf.

♪

Quiet when you need it

"Shut up" switches to soft beeps and queues what happens. "You can talk" brings a short digest of what you missed.

How it works

Built on Pipecat. Local where it counts.

Speech recognition and the voice check run on your Mac's GPU and CPU. Only your own sentences leave the machine.

# 2. keys: OpenRouter, ElevenLabs, Hermes
$ cp .env.example .env
# 3. teach Jarvis your voice (three sentences)
$ uv run jarvis-enroll
# 4. talk
$ uv run jarvis
